# 術語統一規則

輸入 JSON：`{英文名稱: {"variants": {譯名: ["namespace:key@來源", ...]}}}`。來源 `conv`＝CFPA／mod 內建人工譯文轉繁，其他（haiku／sonnet）＝機翻。

對每個英文名稱選一個標準譯名，輸出 `{英文名稱: 標準譯名}`（每個輸入名稱都要有）。

## 選擇順序
1. 有 `conv` 來源的譯名優先（人工翻譯）；多個 conv 譯名時選出現次數最多的。
2. 都是機翻時：選最符合台灣 Minecraft 官方譯名與 `rules/mt_rules.md` 詞彙表的；都不違反時選最簡潔的。
3. 可以給出不在 variants 裡的更好譯名，但只在所有 variants 都有明顯錯誤時。
4. mod 名、材料專有名詞（Allthemodium 等）保留英文時，標準譯名就是英文原文。
5. 台灣繁體用字；保留所有非 ASCII 字元與符號原樣。

## 輸出
用 Write 工具把 JSON 寫到指定輸出路徑（UTF-8、中文直出）。
