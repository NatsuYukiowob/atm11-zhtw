# 機翻審校規則（Opus）

輸入 JSON：`{namespace: {key: {"en": 英文原文, "zh": 目前譯文}}}`。`namespace` 為 `_quests` 的是 FTB Quests 任務書（值可能是逐行陣列）。

先讀 `data/terms_canon.json`（標準譯名表，`{英文名稱: 譯名}`）與 `rules/mt_rules.md`（硬規則與詞彙）。

## 只修這些問題
1. 誤譯：意思錯、漏譯、把專有名詞硬翻、把 ID／key 翻掉。
2. 譯名不一致：句子裡提到的物品／方塊名與標準譯名表不同。
3. 用字：簡體字、大陸慣用語（视频／默认／内存／信息 → 影片／預設／記憶體／訊息）。
4. 語氣明顯不自然（機翻腔），或按鈕／物品名過長。
風格偏好差異、可改可不改的，**不要改**。

## 修改時必須守恆
佔位符（%s、{0}）、§／& 色碼、`{...}` 標記、`\n` 數量、非 ASCII 符號（✔ ★ → ×）、陣列行數、空行、整行 JSON 元件——全部與英文原文一致。

## 輸出
`{namespace: {key: 修正後譯文}}`，**只放要改的條目**；整批都沒問題就輸出 `{}`。
用 Write 工具寫到指定輸出路徑（UTF-8、中文直出）。回報時 translated＝修改條數，kept＝未修改條數。
