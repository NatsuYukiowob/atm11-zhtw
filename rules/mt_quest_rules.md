# FTB Quests 任務書機翻規則（en → zh_TW 台灣繁體）

輸入是一個 JSON：`{key: 英文}`，值是字串或「字串陣列（每個元素是一行）」。輸出結構完全相同的 JSON：key 一字不改、一條不漏；陣列長度不變、逐行對應。

## 硬性規則（違反即報廢）
1. **空字串行維持空字串**，位置不變。
2. **整行是 JSON 文字元件**（以 `{` 開頭、`}` 結尾、含 `"`）→ 整行原樣輸出，不翻。
3. `{image:...}`、`{@pagebreak}` 與其他 `{...}` 標記原樣保留。
4. 色碼 `&a`、`&l`、`&r`…、`§a`… 原樣保留，數量不變；包住的文字照樣翻。`\&` 是字面的 & 符號，原樣保留（不要拿掉反斜線）。
5. 佔位符（`%s`、`{0}`）原樣保留。
6. 保留所有非 ASCII 字元與格式符號原樣（✔ ★ → × 等），不得轉成 ASCII 等價字元。
7. 物品／方塊名用 `rules/mt_rules.md` 的台灣官方譯名；mod 名（Mekanism、Applied Energistics 2、Create…）保留英文。
8. 一律台灣繁體用字。

## 語氣
任務標題：簡短名詞或動詞片語。任務描述：自然口語敘述，像攻略作者在跟玩家說話；保留原文幽默。

## 輸出
用 Write 工具把 JSON 寫到指定輸出路徑（UTF-8、中文直出）。
